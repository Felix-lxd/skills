# Skill template

This is a template to create a new skill in the monorepo. Place a copy under `skills/<skill-name>/README.md` and fill the sections below.

- id: skill.<owner>.<skill-name>
- name: <skill-name>
- short_description: One-line summary
- triggers: ["/command", "keyword1", "keyword2"]
- modes: [review-only, read-only]
- outputs: List of produced artifacts (e.g., ReviewReport, MergeReport)

Sections

1. Overview
2. Metadata (frontmatter)
3. Inputs and triggers
4. Phases (P0..P8) and responsibilities
5. Artifacts (structures and example JSON)
6. Integration points (webhook/event schema)
7. Allowed/forbidden operations (white/black list)
8. Examples
